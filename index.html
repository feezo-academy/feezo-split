👤 Student Details
Add Student
⬆️ Import Students
📋 Required CSV/Excel format:
Name, RollNo, Sport, Batch, DOB, Parent, Contact, Contact2, School, JoinDate
• Name is required. All other columns optional and can be in any order.
• DOB & JoinDate format: DD/MM/YYYY. Age is calculated automatically from DOB.
• Matching an existing student by Name + DOB + Parent name + a matching Contact number updates their details instead of duplicating them.
• First row treated as header and skipped.
📋 Review Import
⬆️ Import Attendance
📋 Required CSV/Excel format:
Name, RollNo, Sport, Batch, DD/MM/YYYY, DD/MM/YYYY, …
• Name or RollNo is required to identify the student.
• Batch must exactly match the student's batch in the app — rows are skipped if it doesn't.
• Add one column per date to mark, with the header as DD/MM/YYYY (e.g. 15/06/2025).
• Fill each date column with P for Present, A for Absent. Leave a cell blank to skip that student for that date.
• First row treated as header and skipped.
📋 Review Import
⬆️ Import Fees
📋 Required CSV/Excel format:
Name, RollNo, Sport, Month, Status, Amount, Method, PaidDate
• Name or RollNo required to identify the student.
• Month format: YYYY-MM (e.g. 2025-06)
• Status: paid or unpaid
• Amount: number (e.g. 1500). Optional.
• Method: Cash / UPI / Card etc. Optional.
• PaidDate: DD/MM/YYYY. Optional.
• First row treated as header and skipped.
